Mathematical Principles

Formal definitions, recurrence relations, and algorithmic complexity.

Problem Formalization

Given capacity W and n products with weight wi and profit pi, select binary indicators xi ∈ {0, 1} to maximize ∑ pixi subject to ∑ wixi ≤ W.

  • Fractional Knapsack: xi ∈ [0, 1]. Solvable via greedy profit/weight density sorting.
  • 0/1 Knapsack: xi ∈ {0, 1}. NP-complete decision problem solved via Dynamic Programming.

Complexity Classification

ApproachTimeSpaceOptimality
Fractional GreedyO(n log n)O(n)Optimal (Fractional)
Heuristic GreedyO(n log n)O(n)Suboptimal (0/1)
Dynamic ProgrammingO(n · W)O(n · W)Optimal (0/1)

DP is pseudo-polynomial because its runtime depends on the numeric magnitude of W.

Greedy: Fractional Logic

Greedy choice property: items with maximum profit per unit weight are prioritized first until capacity limits are reached.

1. Calculate ratio r[i] = p[i] / w[i]
2. Sort items descending by r[i]
3. For item i:
     If w[i] <= remaining_capacity:
         take full item
     Else:
         take (remaining_capacity / w[i])
         break

Dynamic Programming: Bellman Relation

Optimal substructure: optimum solution dp[i][c] utilizes solutions to subproblems involving i-1 items.

dp[0][c] = 0  for all c ∈ [0, W]
For i = 1 to n:
  For c = 0 to W:
    dp[i][c] = dp[i-1][c]
    if w[i] <= c:
      dp[i][c] = max(dp[i][c], dp[i-1][c - w[i]] + p[i])
return dp[n][W]

Architectural Rationale & Mission

StockKnap bridges classical Design & Analysis of Algorithms (DAA) concepts with intuitive, production-grade warehouse inventory optimization systems.

Why Knapsack in Inventory?

Warehouses face physical volume, weight, and forklift limits. When supply exceeds holding capacity, managers must decide which items generate maximum ROI without exceeding thresholds.

The Dynamic Programming Advantage

While intuitive human decisions rely on greedy heuristics ("take the most valuable items first"), whole-item constraints often leave empty space. DP uncovers hidden combinatorial synergies.

Design & Technology Stack

Built with Flask backend and a clean vanilla JavaScript frontend utilizing reactive glassmorphism components, SVG rendering, and zero heavy client-side framework bloat.
